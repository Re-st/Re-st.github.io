재부팅 후 tmux를 복구할 수 있게 하기 (tmux-resurrect)

01 Jan, 2024 [howto] 1 min read

install

1git clone https://github.com/tmux-plugins/tmux-resurrect ~/.tmux/plugins/tmux-resurrect
2cat "run-shell ~/.tmux/plugins/tmux-resurrect/resurrect.tmux" >> .tmux.conf

usage

저장: prefix + Ctrl-s
복원: prefix + Ctrl-r
