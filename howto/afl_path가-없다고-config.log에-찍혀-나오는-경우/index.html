AFL_PATH가 없다고 config.log에 찍혀 나오는 경우

22 Feb, 2024 [howto] 1 min read

Dockerfile 중 /benchmark/build_bench_…sh 의 결과를 보니

See `config.log' for more details

인데, config.log 보면 AFL_PATH가 없다고 나온다. AFL_PATH는 llvm_mode/Makefile에 있는데, 없는 이유는 역시 setup 중에 중간에 터져버린 것이다. setup은 make; cd llvm_mode; make 즉, 컴파일 오류. 이를 보려면 역시 상위폴더 make를 해보자. 문제없다.

원인 발견

지금보니, 이미 make하던 와중에 중단하고 다시한꼴이라 그런가보다. setup 스크립트는 make clean을 먼저한후 make한다.
