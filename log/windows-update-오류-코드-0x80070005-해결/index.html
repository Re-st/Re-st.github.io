Windows Update 오류 코드 0x80070005 해결

01 Jan, 2024 [log] 1 min read

이 오류 코드는 업데이트를 설치하는 데 필요한 파일이나 레지스트리에 대한 사용 권한이 없을 때 발생합니다. 아래 링크를 클릭하시면 해당 오류 코드의 해결 방법이 설명되어 있으니 참고하여 진행해 보시기 바랍니다: Microsoft Answers

해결을 위해 [[(방법) 윈도 공간 부족 해결|(방법) 윈도 공간 부족 해결]]을 했으나 통하지 않았다.

결국 해결한 방법은, 관리자 권한 powershell에서 winget upgrade --all. (일반 사용자 권한이었을 때는 3개의 업데이트만 찾았었는데, 이제는 24개 업데이트)

다른 해결방법으로, winget update만으로 해결할 수 있었을지 모르겠다.
